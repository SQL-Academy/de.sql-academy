Der Operator `CASE` ist das Mittel der Wahl, um bedingte Logik direkt in einer SQL-Abfrage abzubilden.
Damit gibst du Werte basierend auf Bedingungen zurück, ganz ähnlich wie mit `IF-ELSE`.

```sql
CASE
    WHEN condition1 THEN result1
    WHEN condition2 THEN result2
    ...
    ELSE default_result
END
```

## Beispiele

- Kategorien anhand des Gehalts vergeben:
    ```sql
    SELECT name,
        salary,
        CASE
            WHEN salary >= 80000 THEN 'Hoch'
            WHEN salary >= 50000 THEN 'Mittel'
            ELSE 'Niedrig'
        END AS salary_category
    FROM employees;
    ```
