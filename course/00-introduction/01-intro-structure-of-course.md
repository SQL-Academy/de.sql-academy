# Aufbau des Kurses

Der Kurs ist in 6 Module aufgeteilt, das Einführungsmodul nicht mitgezählt. Jedes Modul kannst du dir als Mini-Kurs vorstellen,
der ein bestimmtes Themenbündel rund um SQL abdeckt.

Die Module sind unabhängig voneinander durchführbar, wir empfehlen aber trotzdem, den Kurs der Reihe nach zu bearbeiten.

Am Ende der meisten praxisorientierten Themen findest du den Block "Übungen zur Selbstkontrolle", damit du das Gelernte direkt anwenden kannst.

## Oberflächen

Im Kurs begegnen dir einige nicht ganz alltägliche Komponenten – darum hier eine kurze Beschreibung, wie du damit umgehst.

### Block für ausführbaren Code

Die wohl häufigste Komponente ist der Block für ausführbaren Code. Er sieht so aus:

```sql
SELECT 'Hi, I am code playground 😊' AS hello;
```

Wenn er einen aktiven blauen Button enthält, kannst du den Code ausführen. Beim Klick auf den Button öffnet sich der Code in einem neuen Tab in der Sandbox.

![Beschreibung des Blocks mit ausführbarem Code](https://sql-academy.org/static/guidePage/intro-structure-of-course/de_codeplayground_description.png "Beschreibung des Blocks mit ausführbarem Code")

### Übungen zur Selbstkontrolle

Überspring die Aufgaben am Ende jedes Artikels lieber nicht. Sie sehen so aus:

![Beschreibung der Übungen zur Selbstkontrolle](https://sql-academy.org/static/guidePage/intro-structure-of-course/de_exercises_description.png "Beschreibung der Übungen zur Selbstkontrolle")

Bevor du die Aufgaben löst, solltest du dich in deinem Account anmelden, damit alle Lösungen gespeichert werden.

### KI-Assistent

Wir haben einen smarten Helfer auf Basis künstlicher Intelligenz, der dir gern bei komplexen Themen hilft und alle aufkommenden Fragen beantwortet.

**So sprichst du mit ihm:**

- **Text auf der Seite markieren** – es erscheint ein Button "Erklären", der zusätzliche Erläuterungen zum markierten Abschnitt liefert.

![Button "Erklären" beim Markieren von Text](https://sql-academy.org/static/guidePage/intro-structure-of-course/de_ai_explain.png 'Button "Erklären" beim Markieren von Text')

- **Schnellaktionen** im Assistenten-Fenster, zum Beispiel "Stell mir eine Frage" zur Selbstkontrolle beim aktuellen Thema.

    ![Fenster des KI-Assistenten mit Schnellaktionen](https://sql-academy.org/static/guidePage/intro-structure-of-course/de_ai_window.png "Fenster des KI-Assistenten mit Schnellaktionen")

- **Fehler erklären** – wenn bei einer SQL-Query in den Übungen ein Fehler auftritt, hilft der Assistent dabei, die Ursache zu verstehen und die Query zu korrigieren.

    ![KI-Assistent erklärt einen Fehler in einer SQL-Query](https://sql-academy.org/static/guidePage/intro-structure-of-course/de_ai_explain_error.png "KI-Assistent erklärt einen Fehler in einer SQL-Query")

Der Assistent steht **registrierten Nutzern** zur Verfügung. Jeder Nutzer hat einige kostenlose Anfragen, <a href="https://sql-academy.org/de/premium" target="_blank">Premium-Nutzer</a> haben unbegrenzt viele.
