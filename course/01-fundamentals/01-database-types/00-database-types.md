# Datenbanktypen

Dieser Kurs ist darauf ausgelegt, dass du die Abfragesprache für relationale Datenbanken beherrschst. Sie sind in puncto Beliebtheit anderen Datenbanktypen klar überlegen.

Wir wollen aber, dass du verstehst, dass es nicht nur sie gibt.
Deshalb werfen wir ganz kurz einen Blick auf andere Vertreter der großen Datenbank-Familie.
Sieh es als kleinen Zoo-Besuch 🦁 – ein kurzer Blick auf ein paar ungewöhnliche Tiere.

Den relationalen Datenbanken widmen wir uns danach natürlich ausführlich.

Klassifizierungen von Datenbanken gibt es viele, aber die gefragtesten sind diese:

| Datenbanktyp        | Beschreibung                                       |
| ------------------- | -------------------------------------------------- |
| Relationale         | Daten in verknüpften Tabellen — Zeilen und Spalten |
| Key-value           | Schneller Zugriff auf einen Wert per Schlüssel     |
| Dokumentorientierte | Flexible Dokumente im JSON-Format                  |
